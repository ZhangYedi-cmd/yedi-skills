## watchdog.sh 修复记录

### 问题 1：ACPX 命令缺少 agent 前缀 + cwd
- 根因：`acpx sessions show "task_id"` 没带 agent 子命令（如 `claude`/`codex`），且没 cd 到对应 worktree
- 正确命令：`cd $worktree && acpx $agent sessions show $task_id`
- 修复：新增 `get_task_agent()` / `get_task_worktree()` / `run_acpx()` 统一入口
- 影响范围：`monitor_acpx_task` / `run_recovery` / `request_callback_correction` / `handle_callback` 中所有 ACPX 命令
- 状态：已修复并验证通过

### 问题 2：agent 完成后 status 仍报 running，callback 检测不触发
- 根因：`monitor_acpx_task` 中 `if status == running then return 1`，直接跳过 callback 检测
- 但 ACPX agent 完成任务后不会变成 dead/idle，status 保持 running（等下一个 prompt）
- 修复方案（已规划未实施）：每次巡检都检查 sessions read 有无新 callback-json，不再以 status 为前置条件
- 状态：待修复
