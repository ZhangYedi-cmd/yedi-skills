**页面 icon**：🔄

### 首次创建（仅在页面不存在时）

如果搜索 Notion 找不到"复盘日记"页面，用 notion-create-pages 创建：
- 创建为顶级页面（无 parent）
- 标题："复盘日记"
- icon："🔄"

创建后将页面 ID 更新到上方表格中。

### 内容组织方式

页面内容按时间倒序排列（最新的在最上面），按月分组：

```markdown
# 3月

## 📆 3.23 日复盘
...

## 📆 3.22 日复盘
...

## 📅 第 12 周复盘（3.17 - 3.23）
...

# 2月
...
```

### 写入操作

1. 先用 notion-fetch 获取复盘日记页面的当前内容
2. 找到当前月份的标题（如 `# 3月`）
3. 用 notion-update-page 的 `update_content` 命令：
   - `old_str`：当前月份标题行
   - `new_str`：当前月份标题 + 新复盘条目 + 原有内容

如果当前月份标题不存在（新月份的第一条），在页面分隔线 `---` 之后插入新的月份标题和复盘条目。

### 防重复检查

写入前检查页面内容中是否已存在：
- 日复盘：`## 📆 {M.DD} 日复盘`
- 周复盘：`## 📅 第 {N} 周复盘`

如果已存在，询问用户是否覆盖。

## 读取日记内容

### 日期匹配规则

两个日记页面的条目都以 `### {M.DD}` 或 `## {M.DD}` 格式标记日期。

读取步骤：
1. 用 notion-fetch 获取页面全文
2. 按日期标题分割内容
3. 匹配目标日期范围的条目

### 日期范围计算

- **日复盘**：当天日期（如 `3.23`）
- **周复盘**：本周一至今天（如 `3.17` 到 `3.23`）
- 周数计算：使用 ISO 周数
