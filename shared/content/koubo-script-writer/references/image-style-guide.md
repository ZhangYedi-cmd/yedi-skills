# 配图 Prompt 写法与默认风格模板

## 优先级：复用 > 新建

先检查输出目录（或用户指定目录）下有没有已存在的 prompt 文件（常见路径 `assets/prompts/*.md`）。**只要系列里已经定过角色和配色，新图必须原样复用那段描述文字**，不要意译、不要"我觉得这样更好看"地改写——角色跑偏是配图系列最容易翻车的地方。

只有全新系列、目录下完全没有历史 prompt 时，才用下面的默认模板起草一套新角色，起草完先给用户看一眼再出图。

## 单张 prompt 文件的结构

```markdown
# 画面内容：{这张图的用途，比如"竖版封面"/"第 N 段配图：xxx"}（最终尺寸 {宽x高}，{比例}）

{延续系列统一角色/配色的一句话引用，比如"延续本系列同一套角色、同一配色体系：..."}

**关键构图约束**：{如果最终会被裁切/嵌入到特定位置，写清楚安全区域和留白比例，防止裁切时切掉关键内容}

{分点描述画面里每个元素的位置、动作、要渲染的文字（用引号标出要渲染的确切中文/英文字符串）}

只渲染引号内给定的字符串，不要自行添加多余文字，严禁乱码、错别字或英文占位符文本。
```

要点：
- **画面里要出现的文字必须用引号精确写出**，AI 出图对图内文字的还原能力有限，写得越精确越不容易乱码。
- **写清楚构图安全区**，尤其是封面/横幅这类会被平台裁切（抖音封面裁竖版、公众号首图裁横版）的图，明确告诉模型哪块区域不能放关键内容。
- **不要堆信息**，一张图表达一个场景/一个流程，宁可多出几张单张信息量小的图，不要一张图塞满导致文字全乱码。

## 默认角色模板（仅在全新系列时使用，出图前先给用户确认）

风格基调：暖色系插画风格，干净疏朗，不做写实肖像。

```
暖米白背景（#F7F2E7），蓝黑双色手写感粗体大字，蓝色（#3D5AFE 系）主色点缀，深炭色文字。
主角：一位戴眼镜的工程师，蓝色连帽卫衣，自然表情，动作随意放松（比如单手插兜、抱着笔记本电脑）。
配角：一个圆润可爱的白色机器人，探出半个身子，姿态活泼。
```

如果内容主题不适合"工程师+机器人"这套人设（比如非技术话题），不要硬套这个模板——按主题重新设计一套角色，但同样要求：**同一系列内，角色/配色描述原样复用，不二次创作**。

## 尺寸与用途对照

| 用途 | 比例 | 何时需要 |
|---|---|---|
| 封面（横版） | 16:9 | 默认必需，知识库/公众号首图用 |
| 封面（竖版） | 9:16 | 明确要发抖音/短视频平台时加 |
| 正文配图 | 16:9 或 1:1 | 每个主体段落按需 1 张 |
| 主页横幅 | 5:1（超宽扁形） | 仅当用户明确要做主页/频道横幅时才生成，不是默认产物 |

出图时用 `baoyu-image-gen` 的 `--ar` 参数对应传比例，具体调用方式见 `../SKILL.md` Step 5。
