# 万物图鉴封面生成器 v2.0

将任意主题转化为一张高信息密度的复古百科插画封面。

本技能的所有视觉规范均来自对 @万物图鉴 真实发布封面的逆向分析，
非基于任何已有 Skill 模板。

---

## Usage

```
/wanwu-cover 十二生肖古代雅称与祝福
/wanwu-cover 中国十大国粹 --comp group-portrait
/wanwu-cover 人生十则 --comp center-radial
/wanwu-cover 除夕做这些会提升运气 --comp c-surround
/wanwu-cover --comp pyramid --title "十二生肖性格分析"
```

## Options

| Option | Values | Default |
|--------|--------|---------|
| `--comp <c>` | group-portrait, center-radial, scatter-concept, pyramid, c-surround | 自动推断 |
| `--style <s>` | anthropomorphic, traditional, realistic | 自动推断 |
| `--orientation` | portrait / landscape | portrait |
| `--title <t>` | 自定义标题 | 从主题提取 |
| `--quick` | 跳过确认 | false |

## Workflow（5 步）

```
万物图鉴封面 进度：
- [ ] Step 1: 分析主题 — 确定标题/构图/风格/主要元素
- [ ] Step 2: 确认方案 ⚠️ REQUIRED（除非 --quick）
- [ ] Step 3: 组装 Prompt（按 references/prompt-assembly.md 的 9 模块拼接）
- [ ] Step 4: 调用图片生成技能出图
- [ ] Step 5: 完成报告
```

### Step 1: 分析主题

确定以下关键信息：

1. **主标题**（中文）：用户指定 或 从内容提取
2. **英文副标题**：翻译 + 学术化润色
3. **风格变体**：按自动推荐矩阵 或 用户指定
4. **构图模板**：按自动推荐矩阵 或 用户指定
5. **主体元素清单**：**优先使用人物角色（2-3个）作为视觉锚点** + 物品（4-8个）+ 散落元素
6. **动态动作**：每个人物/关键物品需指定动态动作（倒茶、挥毫、舞蹈等）
7. **印章内容**：2-4 个角标印章文字 + 2-3 个散布印章文字
8. **底部信息栏**：属性列表 / 十二地支 / 其他总结文字

**自动推荐矩阵**：

| 内容信号 | Style | Composition |
|----------|-------|-------------|
| 生肖/神话/拟人动物 | anthropomorphic | group-portrait |
| 犬猫/动植物品种 | realistic | group-portrait |
| 分类/大全/国粹/文化 | traditional | group-portrait |
| 规则/方法/X种行为 | traditional | center-radial |
| 人生/哲理/准则 | traditional | center-radial |
| 习俗/节日/仪式 | traditional | c-surround |
| 排名/等级/TOP | traditional | pyramid |

### Step 2: 确认方案

使用 AskUserQuestion 确认：
- 构图模板
- 风格变体
- 主要元素清单（人物 + 物品）
- 标题 / 副标题

### Step 3: 组装 Prompt

严格按照 `references/prompt-assembly.md` 的 **9 模块** 顺序拼接。
Prompt 保存至 `{output-dir}/prompt.md`。

### Step 4: 生成图片

调用可用的图片生成技能，输出至 `{output-dir}/cover.png`。
失败自动重试一次。

### Step 5: 完成报告

```
万物图鉴封面完成！

主题: [topic]
标题: [title]
风格: [style]
构图: [composition]
路径: [output path]

文件:
✓ prompt.md
✓ cover.png
```

## 核心视觉 DNA（所有构图共享）— v2.0

详见 `references/visual-dna.md`，以下为摘要：

### 渲染风格（v2.0 重大更新）

**丝滑数字插画**，非工笔线稿：
- 平滑精细的数字绘画，丰富色彩深度，柔和体积感光影
- 每个表面都有丝滑渐变 — 无硬边、无平涂
- 轮廓线柔和融入画面（非独立粗墨线）
- 写实度 85-90%：质感清晰可辨（瓷釉、金属、丝绸、木纹）同时保持插画品质
- 整体感觉：高端咖啡桌画册封面 — 平滑、丝滑、精致

### 色彩体系
- **背景**：做旧暖褐宣纸 #E8D5B0 ~ #F5E6C8，微斑驳纸纹，无重度做旧
- **主墨色**：深褐 #3A2A1A ~ #5C3D2E（标题/线条）
- **印章红**：朱砂红 #C0392B ~ #C41E1E（印章/强调/标签）
- **点缀金**：#DAA520 ~ #FFD700（元宝/高光/祥瑞元素）
- **辅助绿**：墨绿 #2E5E4E ~ #3B7A57（植物/竹叶）
- **整体饱和度**：70-85%（丰富鲜艳但暖调，非寡淡）
- **整体亮度**：L值 70-80%（中高亮度，无大面积深色区）

### 双边框系统（v2.0 新增）

```
┌─ 画布边缘 ──────────────────────────────┐
│  ┌─ 外框线 (距边 ~3%) ──────────────┐   │
│  │  [角标印章贴在外框上]              │   │
│  │  ┌─ 内框线 (距边 ~7-8%) ─────┐   │   │
│  │  │                            │   │   │
│  │  │   90% 主体内容聚拢于此     │   │   │
│  │  │                            │   │   │
│  │  └────────────────────────────┘   │   │
│  │  ← 呼吸带：安静宣纸区 (4-5%) →   │   │
│  └───────────────────────────────────┘   │
│  [底部信息栏 L4]                          │
└──────────────────────────────────────────┘
```

- **外框**：细棕色线 + 四角云卷角花
- **内框**：第二道细线 — **主体内容边界**
- **呼吸带**：外框与内框之间，基本留空（仅印章、少量溢出元素）
- **选择性破框**：2-4 个元素突破内框进入呼吸带，制造层次感

### 内容聚拢 + 选择性破框（v2.0 核心构图原则）

**聚拢**：90% 的内容（人物、物品）紧密排布在内框之内，构图紧凑饱满。

**破框**（仅以下元素可突破内框线）：
- 1个人物从侧边延伸入场（被画布边缘裁切，暗示画外空间）
- 1-2个物品（毛笔/绣框）突破上方或侧边内框
- 2-3个散落小元素（棋子/花瓣）跨越内框线落入呼吸带
- 效果："contained with selective overflow" — 收中有放

### 人物 + 动态（v2.0 核心构图原则）

**优先使用人物作为视觉锚点**，非纯静物：
- 2-3 个人物角色（京剧花旦/武术宗师/汉服仕女/书法家等）
- 每个人物有**动态动作**（倒茶、挥毫、舞蹈、出拳）
- 物品也有动态（茶在倒、笔在写、墨在飞溅）
- 画面要"活的"，非博物馆标本静态陈列

### 微观细节（v2.0 新增 — 区分高级感的关键）

**每个物件必须有微观光影细节**：
- **金属**：银针/铜钱有沿长度方向的高光线 + 针尖4点星芒闪烁（✦）
- **玉石**：围棋子有深色玉石光泽 + 单个亮点高光
- **液体**：茶汤半透明 + 背光照射产生琥珀色透光 + 杯中涟漪
- **丝线**：刺绣丝线有方向性光泽，不同角度反光不同
- **纸张**：剪纸有厚度感 + 微卷边 + 底部投影
- **瓷器**：多处弧面高光反射（口沿/瓶身/底部）+ 釉下花纹深度
- **布料**：织纹/丝绸缎面光泽 + 柔和方向性光影
- **散落元素**：花瓣有正反面区分，每个小物件有微小投影

### 文字系统
- **L1 主标题**：毛笔书法体，粗细笔画变化+墨迹渗透边缘，用「」括号。**绝非**印刷黑体
- **L2 英文副标题**：小号衬线体（Garamond 风格），紧跟中文标题下方
- **L3 署名**：「作者：知渡」或自定义，手写风小字
- **L4 底部信息栏**：属性名用中点/圆点分隔横排，位于外框区域
- **L5 印章内文**：2-4 字中文，白文印/朱文印混用

### 印章系统
- **角标印章**：2-4 枚方形红印，贴在**外框线**上
  - 左上 + 右上 必有，左下 + 右下 可选
  - 内容：品牌词（"博物志"、"传统智慧"、"古今图鉴"、"鉴藏珍图"等）
  - 样式：边缘做旧残破，部分阴刻部分阳刻
- **散布印章**：额外 2-3 枚红印分散于画面中部/下部
- **功能**：品牌辨识 + 增加权威感 + 朱砂红贯穿全图

### 绝对禁用
- 维多利亚/西式花纹边框
- Anime/漫画/3D CGI 风格
- 高饱和霓虹色
- 伪拉丁学名文字
- 照片写实人脸
- **平涂工笔线稿风（太素描感）**
- **静态博物馆标本陈列感**

## 5 种构图模板

详见 `references/compositions.md`，以下为摘要：

### 1. group-portrait（群像集合式）
对标：十二生肖古代雅称、中国十大国粹
- 核心：**2-3个人物角色（动态）** + 6-10 个物品紧密铺满
- 人物作为视觉锚点，物品环绕填充
- 内容聚拢在内框内，少量元素破框
- 层次：前景（大且清晰）→ 中景（中等）→ 远景（建筑剪影 15-20%）

### 2. center-radial（中心辐射式）
对标：人生十则
- 核心：中央概念物件 + 6-12 个子概念放射排列
- 每个物件配标注文字（序号+名称）
- 呈现"博物柜陈列"效果
- 可混合人物手部/局部

### 3. scatter-concept（散点概念式）
对标：人生十则（变体）
- 物件均匀散布，无明确中心
- 每个物件 = 一个独立概念
- 配标注文字说明

### 4. pyramid（金字塔层次式）
对标：十二生肖性格分析
- 顶部核心角色（最重要/最强大）
- 中层次要角色 → 底层基础角色
- 近乎左右对称，视觉稳定

### 5. c-surround（C型环绕式）
对标：除夕做这些会提升运气
- 中央焦点物件（供桌/香炉等）
- 周围物件呈 C 型或环状分布
- 色彩最浓烈（大面积红色）

## 3 种风格变体

| Style | 特征 | 饱和度 | 写实度 | 适用 |
|-------|------|--------|--------|------|
| **anthropomorphic** | 拟人化动物穿古装，丝滑数字渲染，服饰纹理细腻 | 75-85% | 85-90% | 生肖、神话、动物合集 |
| **traditional** | 丝滑数字插画+传统百科美感，柔和体积感光影 | 70-85% | 85-90% | 通用百科、文化、哲理 |
| **realistic** | 高质量博物画写实风，明确光影和质感 | 70-80% | 85-95% | 犬猫品种、动植物 |

> **v2.0 变更**：所有风格都从"工笔线稿+淡彩"升级为"丝滑数字插画"渲染。
> 写实度从 70-80% 提升至 85-90%。饱和度从 40-65% 提升至 70-85%。
