# 印章系统

> Prompt 拼装块见 `workflows/prompt-assembly.md` Module 6。

## 角标印章

| 位置 | 必选性 | 放置 | 常见内容 |
|------|--------|------|---------|
| 左上 | 必须 | 贴外框线 | 博物志、国粹、物志 |
| 右上 | 必须 | 贴外框线 | 古今图鉴、华夏文明 |
| 左下 | 可选 | 贴外框线 | 千年传承、智慧图鉴 |
| 右下 | 可选 | 贴外框线 | 十艺精华、鉴藏珍图 |

## 印章样式

```
形状：正方形或竖长方形
尺寸：画面宽度 5-8%
颜色：朱砂红 #C0392B
做旧：边缘不规则残破、部分笔画缺损
类型：白文印（多）+ 朱文印（少）
```

## 散布印章

```
数量：2-3 枚
位置：内框内画面中部空白处
尺寸：略小于角标（3-6%）
内容：与主题相关小词
```
