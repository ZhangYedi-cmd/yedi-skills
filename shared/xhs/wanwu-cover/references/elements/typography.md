# 文字系统（5 层级）

> Prompt 拼装块见 `workflows/prompt-assembly.md` Module 5。

## L1: 主标题

```
字体风格：毛笔书法体，手写感，粗细笔画变化明显
笔触特征：横细竖粗，撇捺舒展，起笔重收笔轻
墨迹效果：边缘有轻微渗透/飞白，非锐利数字边缘
格式：用「」括号包裹标题
颜色：深墨色 #3A2A1A
位置：画面顶部居中，占画面高度约 12-15%
```

**⚠️ CRITICAL**: L1 必须指定为"brush calligraphy / 毛笔书法"风格。

## L2: 英文副标题

```
字体风格：小号衬线体（Garamond/Playfair Display 风格）
位置：紧跟 L1 下方，居中
颜色：中墨色 #5C3D2E
```

## L3: 署名

```
内容：「作者：知渡」或自定义
位置：画面中下部
颜色：中墨色，半透明 70-80%
```

## L4: 底部信息栏

```
位置：外框区域，画面底部 8% 区域
内容格式（4 种变体）：
  A) 中点分隔：「書法 · 武术 · 中医 · 京剧 · 汉服」
  B) 地支横排：「子丑寅卯辰巳午未申酉戌亥」
  C) 说明文句：「描述句 · 描述句 · 描述句」
  D) 拉丁学术风：「Animalia Zodiacus · Duodecim Genera」
颜色：#5C3D2E
```

## L5: 印章内文

```
字体：篆书或隶书风格
内容：2-4 字中文
类型：白文印（阴刻，红底白字）/ 朱文印（阳刻，白底红字）
```
