# 万物图鉴封面 — 完整视觉 DNA 规范 v2.0

> 所有数据来自对 @万物图鉴 实际发布封面的逆向视觉分析。
> 本文档定义所有构图模板共享的固定视觉元素。
> v2.0 基于"中国十大国粹"封面 7 轮迭代优化。

---

## 1. 渲染风格（v2.0 重大更新）

### 1.1 核心定义

```
渲染类型：丝滑数字插画（Polished Digital Illustration）
非：工笔白描线稿 + 淡彩填色（v1.0 已弃用）
非：3D CGI / 照片写实

关键词：smooth, refined, silky-smooth, volumetric shading, seamless gradation
写实度：85-90%
品质感：高端咖啡桌画册封面
```

### 1.2 渲染要求

| 要素 | 要求 | 禁止 |
|------|------|------|
| 表面 | 丝滑渐变，无硬边 | 平涂、硬边 |
| 轮廓 | 柔和融入画面 | 独立粗墨线、素描线条 |
| 光影 | 柔和方向性光（左上方），每个物体有高光+暗面 | 无阴影的平面化、强硬阴影 |
| 色彩过渡 | 无缝渐变 | 色块拼接 |
| 整体感 | 精致、丝滑、圆润 | 粗糙手绘感、素描扫描件 |

## 2. 色彩体系

### 2.1 核心色板

| 角色 | 色值 | 用途 |
|------|------|------|
| 宣纸底色 | `#E8D5B0` ~ `#F5E6C8` | 全画面背景底色 |
| 宣纸亮色 | `#F5EED8` ~ `#FAEBD7` | 高光区域 |
| 主墨色-深 | `#3A2A1A` | 主标题、最深线条 |
| 主墨色-中 | `#5C3D2E` | 次级文字、描边 |
| 主墨色-浅 | `#8B6914` | 装饰线、边框 |
| 朱砂红-正 | `#C0392B` | 印章主色 |
| 朱砂红-亮 | `#C41E1E` | 强调元素、标签边框 |
| 朱砂红-暗 | `#922B21` ~ `#8B2500` | 印章阴刻、暗部 |
| 点缀金-正 | `#DAA520` | 元宝、铜钱、辉光 |
| 点缀金-亮 | `#FFD700` | 高光金 |
| 辅助绿 | `#2E5E4E` ~ `#3B7A57` | 竹叶、植物、自然元素 |

### 2.2 色彩参数（v2.0 更新）

| 参数 | v1.0 数值 | v2.0 数值 | 说明 |
|------|-----------|-----------|------|
| 整体色温 | 4500K ~ 5500K | 4800K ~ 5500K | 偏暖 |
| **饱和度** | **40% ~ 65%** | **70% ~ 85%** | **丰富鲜艳但暖调** |
| 亮度 (L值) | 70% ~ 80% | 70% ~ 80% | 不变 |
| **写实度** | **70% ~ 80%** | **85% ~ 90%** | **更丝滑精致** |
| 标题对比度 | 7:1 ~ 10:1 | 7:1 ~ 10:1 | 不变 |
| 印章对比度 | 8:1+ | 8:1+ | 不变 |

### 2.3 三种风格的色彩能量

| Style | 色彩能量 | 饱和度范围 | 特征 |
|-------|---------|-----------|------|
| anthropomorphic | WARM-VIBRANT | 75-85% | 服饰色彩鲜明，暖色占主导 |
| traditional | WARM-RICH | 70-85% | 丰富暖色，柔和体积感 |
| realistic | NATURAL-RICH | 70-80% | 自然画感+丰富质感 |

### 2.4 红色分布原则

朱砂红贯穿全画面：
- 2-4 个角标印章（必须）
- 2-3 个散布印章（必须）
- 部分主体元素的红色装饰（衣服、旗帜、灯笼、剪纸等）
- 全图合计 6-12 处红色触点

## 3. 双边框系统（v2.0 新增）

### 3.1 结构

```
┌─ 画布边缘 ──────────────────────────────┐
│  ┌─ 外框线 (距边 ~3%) ──────────────┐   │
│  │  [角标印章贴在外框线上]            │   │
│  │  ┌─ 内框线 (距边 ~7-8%) ─────┐   │   │
│  │  │                            │   │   │
│  │  │   90% 主体内容聚拢于此     │   │   │
│  │  │                            │   │   │
│  │  └────────────────────────────┘   │   │
│  │  ← 呼吸带 (4-5% 安静宣纸) →      │   │
│  └───────────────────────────────────┘   │
│  [底部信息栏 L4]                          │
└──────────────────────────────────────────┘
```

### 3.2 规格

| 层 | 距画布边缘 | 线条 | 内容 |
|----|-----------|------|------|
| 外框线 | ~3% | 细棕色线 #8B6914 | 四角云卷角花（淡金/深褐） |
| 呼吸带 | 3-8% | 无线条 | 基本留空，仅印章+少量溢出元素 |
| 内框线 | ~7-8% | 细棕色线 | 可选回纹(回纹)微纹饰 |

### 3.3 内容聚拢 + 选择性破框

**聚拢规则**：90% 的内容（人物、物品、文字龙字等）紧密排布在内框之内。

**破框规则**（仅以下可突破内框线）：
- 1 个人物从侧边入场（被画布边缘裁切 ~20%）
- 1-2 个物品突破上方或侧边内框（毛笔杆/绣框被裁切）
- 2-3 个散落小元素（棋子/花瓣）跨越内框线落入呼吸带
- 破框元素在呼吸带中有微小投影

### 3.4 边缘裁切

关键构图技法 — 暗示画面比画布大：
- 人物从侧边被画布裁切（只显示 ~80%）
- 物品（毛笔/绣框/人参）被上方或侧边裁切
- 花瓣/飘散元素跨越画布边缘

## 4. 人物与动态（v2.0 新增）

### 4.1 人物优先原则

**优先使用人物角色（2-3个）作为视觉锚点**：

| 主题类型 | 推荐人物 | 动态动作 |
|----------|----------|----------|
| 文化/国粹 | 京剧花旦、武术宗师、汉服仕女 | 甩袖、出拳、起舞 |
| 生肖/神话 | 拟人化动物角色 | 持道具、行礼、战斗姿态 |
| 哲理/人生 | 书法家、茶人、学者 | 挥毫、倒茶、翻书 |
| 自然/品种 | 可无人物，或观察者手部 | 持放大镜、抚摸、采摘 |

### 4.2 动态要求

- 人物必须有动作姿态（非站桩呆立）
- 物品也要有动态（茶在倒、笔在写、墨在飞溅、棋在落子）
- 散落元素有飘动感（花瓣飘、丝带飞、茶叶散）
- 整体画面"活的"，非博物馆标本

## 5. 微观细节系统（v2.0 新增 — 区分高级感的关键）

### 5.1 总原则

```
每个金属表面 → 高光线 + 星芒闪烁（✦）
每个光滑表面 → 弧面高光反射
每个透明/半透明材质 → 光线穿透效果
每个散落小物件 → 微小投影
每个布料 → 织纹/丝线方向性反光
```

### 5.2 材质细节清单

| 材质 | 微观细节要求 |
|------|------------|
| **银针/金属** | 沿长度高光线 + 针尖4点星芒（✦）+ 铜金色螺旋线柄 |
| **围棋子** | 黑子：深玉石光泽 + 单亮点。白子：温润半透明 + 柔和rim光 |
| **茶汤液柱** | 半透明 + 背光琥珀色透光 + 液面涟漪 + 蒸汽边缘透光 |
| **刺绣丝线** | 方向性光泽（不同角度反光不同）+ 绣框木纹清晰 |
| **剪纸** | 纸张厚度感 + 切边微卷 + 底部投影 |
| **瓷器** | 多处弧面高光（口沿/瓶身/底部）+ 釉下花纹有深度感 |
| **布料/丝绸** | 缎面光泽 + 织纹走向 + 柔和褶皱阴影 |
| **人参/草药** | 根须细节 + 湿润蜡质表面光泽 |
| **毛笔** | 笔毫根根可辨 + 笔尖墨水饱满欲滴 |
| **铜钱** | 铜绿氧化质感 + 凸起字纹 + 微小投影 |
| **花瓣** | 正反面区分 + 叶脉纹路 + 半透明边缘 |

## 6. 文字系统（5 层级）

### L1: 主标题

```
字体风格：毛笔书法体，手写感，粗细笔画变化明显
笔触特征：横细竖粗，撇捺舒展，起笔重收笔轻
墨迹效果：边缘有轻微渗透/飞白，非锐利数字边缘
格式：用「」括号包裹标题
颜色：深墨色 #3A2A1A
位置：画面顶部居中，占画面高度约 12-15%
```

**⚠️ CRITICAL**: L1 必须指定为"brush calligraphy / 毛笔书法"风格。

### L2: 英文副标题

```
字体风格：小号衬线体（Garamond/Playfair Display 风格）
位置：紧跟 L1 下方，居中
颜色：中墨色 #5C3D2E
```

### L3: 署名

```
内容：「作者：知渡」或自定义
位置：画面中下部
颜色：中墨色，半透明 70-80%
```

### L4: 底部信息栏

```
位置：外框区域，画面底部 8% 区域
内容格式（4 种变体）：
  A) 中点分隔：「書法 · 武术 · 中医 · 京剧 · 汉服」
  B) 地支横排：「子丑寅卯辰巳午未申酉戌亥」
  C) 说明文句：「描述句 · 描述句 · 描述句」
  D) 拉丁学术风：「Animalia Zodiacus · Duodecim Genera」
颜色：#5C3D2E
```

### L5: 印章内文

```
字体：篆书或隶书风格
内容：2-4 字中文
类型：白文印（阴刻，红底白字）/ 朱文印（阳刻，白底红字）
```

## 7. 印章系统

### 7.1 角标印章

| 位置 | 必选性 | 放置 | 常见内容 |
|------|--------|------|---------|
| 左上 | 必须 | 贴外框线 | 博物志、国粹、物志 |
| 右上 | 必须 | 贴外框线 | 古今图鉴、华夏文明 |
| 左下 | 可选 | 贴外框线 | 千年传承、智慧图鉴 |
| 右下 | 可选 | 贴外框线 | 十艺精华、鉴藏珍图 |

### 7.2 印章样式

```
形状：正方形或竖长方形
尺寸：画面宽度 5-8%
颜色：朱砂红 #C0392B
做旧：边缘不规则残破、部分笔画缺损
类型：白文印（多）+ 朱文印（少）
```

### 7.3 散布印章

```
数量：2-3 枚
位置：内框内画面中部空白处
尺寸：略小于角标（3-6%）
内容：与主题相关小词
```

## 8. 装饰系统

### 8.1 祥云/云纹
极淡（10-20%），四角+主体间过渡，不抢主体。

### 8.2 做旧纹理
宣纸纤维质感 + 极淡茶渍斑（15-25%）+ 轻微暗角 vignette。
注意：**轻度做旧**，不能像破旧纸张。

### 8.3 金色元素
元宝、铜钱、金色光晕 — 吉祥/财富主题增加。

### 8.4 散落元素
与主题相关的小物件（棋子、墨滴、花瓣、茶叶、铜钱），3-8 个，很小（1-3%），有微小投影。

### 8.5 背景深度
极淡建筑/山水剪影（故宫/山脊）15-20% 透明度，增加文化氛围。

## 9. 画布规格

### 竖版（主流）
```
尺寸：1792 × 2400 px（3:4）
安全区：外框线内（距边 3%）
内容区：内框线内（距边 7-8%）
```

### 横版
```
尺寸：1920 × 1080 px（16:9）或 1660 × 1242 px（4:3）
```

## 10. 绝对禁用清单

```
- 维多利亚/洛可可/巴洛克西式边框
- Anime/漫画/3D CGI
- 高饱和霓虹色/荧光色
- 伪拉丁学名文字
- 照片写实人脸
- 纯白色背景
- 现代无衬线字体标题
- 渐变色背景
- 平涂工笔线稿风（太素描感、太水彩淡薄）
- 静态博物馆标本陈列感
- 粗糙手绘感/可见铅笔线条
```
