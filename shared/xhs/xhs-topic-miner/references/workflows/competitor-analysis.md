# 竞品分析工作流

## 前置条件

- 必须：可访问 `xiaohongshu-mcp.user_profile`
- 必须：至少 1 个竞品 URL（含 `xsec_token`）
- 可选：已完成 `init`（若未 init，仅生成分析报告，不涉及支柱配置）

## 数据获取

### 通过 xiaohongshu-mcp
```
工具：user_profile
输入：user_id + xsec_token（从博主主页 URL 提取）
输出：博主基本信息 + 笔记列表（标题、点赞数、封面）
```

### 通过 agent-reach
```
命令：agent-reach search-xhs "关键词"
用途：发现同领域竞品账号、搜索话题热度
```

## 分析步骤

### Step 1: 数据采集

```
输入：竞品博主 URL（1-3 个）
操作：
  1. 提取 user_id 和 xsec_token
  2. 调用 user_profile 获取全部笔记
  3. 记录每篇笔记：标题、点赞数、类型
输出：raw-data-{博主}.json
```

### Step 2: 爆款识别

```
定义 TOP 20%：按点赞数排序取前 20%
计算基准线：
  - 平均赞 = 总赞数 / 笔记数
  - 爆款线 = 平均赞 × 2（超过此值为爆款）
  - 高赞线 = 平均赞 × 5（超过此值为超级爆款）
```

### Step 3: 题材聚类

```
对每篇笔记的标题进行语义分类：
  - 传统智慧/哲理
  - 自然/动植物
  - 文化/民俗/历史
  - 生活/美食/健康
  - 趣味/排行/冷知识
  - 其他

统计每个类目：
  - 笔记数量
  - 平均赞
  - 最高赞
  - 占总笔记比例
  - 爆款率（该类目爆款数 / 该类目总数）
```

### Step 4: 标题模式提取

```
对爆款笔记的标题做模式分析：

1. 结构模式：
   - [数字]+[量词]+[名词] → 占比 XX%
   - [名词]+[悬念词]+[结论] → 占比 XX%
   - [身份/场景]+[主题] → 占比 XX%
   - 其他 → 占比 XX%

2. 数字偏好：
   统计出现频率最高的数字

3. 情绪词提取：
   统计高频出现的形容词/副词

4. 标题长度：
   统计字数分布（最短/最长/平均/中位数）
```

### Step 5: 内容空白发现

```
1. 搜索竞品领域的核心关键词
2. 收集小红书搜索联想词
3. 对比竞品已发列表
4. 标记未覆盖的话题
5. 用 search_feeds 验证这些话题的搜索热度
```

### Step 6: 生成分析报告

输出 `analysis-{博主昵称}.md`，格式参见 gaps-analysis.md 中的输出模板。

## 多竞品交叉分析

当分析 2-3 个竞品时，额外做：

```
1. 共性分析：所有竞品都做的话题 = 验证过的安全选题
2. 差异分析：只有部分竞品做的话题 = 潜在机会
3. 空白分析：所有竞品都没做的话题 = 蓝海或伪需求（需搜索验证）
4. 互动对比：同一话题不同竞品的互动差异 = 角度/执行力的差距
```
