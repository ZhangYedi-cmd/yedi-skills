# 选题生成工作流

## 前置条件

- 必须：`topic-miner/config/pillars.yaml`
- 推荐：至少 1 份 `analysis-*.md`（提供竞品证据）
- 可选：最近 1 份 `research-*.md`（补充热点与 gap 证据）

降级规则：
- 若缺 `analysis-*.md`，跳过「路径 2：竞品延伸法」，并在输出里标注 `degraded_paths: [competitor_extend]`。
- 若缺 `research-*.md`，不影响主流程，但会降低热点/缺口证据强度。

## 四条生成路径

选题不靠「灵感」，而是用**四条系统化路径**并行产出候选选题：

### 路径 1：矩阵填充法

> 从 Content Pillar × Bucket 矩阵中选择**未覆盖的格子**

```
输入：当前矩阵的覆盖状态（哪些格子已做过、效果如何）
操作：
  1. 找出空白格子（从未做过的 Pillar×Bucket 组合）
  2. 找出高效格子的相邻格子（已验证有效的方向的延伸）
  3. 在目标格子中用 AI 发散 5-10 个具体选题
输出：带矩阵坐标的选题列表
```

**示例**：
```
P1传统智慧 × B4对比 = 空白格子
→ 发散：儒vs道、中医vs西医、太极vs瑜伽、茶道vs咖啡道...
```

### 路径 2：竞品延伸法

> 从竞品爆款**延伸、细分、翻新**

四种延伸策略：

| 策略 | 方法 | 示例 |
|------|------|------|
| **续集** | 爆款的第二期/系列化 | "四大系列"→"四大系列【2】【3】" |
| **细分** | 爆款大主题的子话题深挖 | "中国十大国粹"→"国粹之首：书法的前世今生" |
| **翻新** | 同一话题换角度/换形式 | "九大凶花"(分类)→"凶花vs吉花对比图鉴"(对比) |
| **组合** | 两个爆款话题的交叉 | "人生铁律"+"修身九要"→"修身的科学与哲学" |

### 路径 3：搜索热点法

> 从**平台搜索数据**中发现用户真实需求

```
操作：
  1. 在小红书搜索核心领域关键词（图鉴/科普/冷知识/排行...）
  2. 收集搜索下拉联想词
  3. 用 search_feeds 搜索这些联想词
  4. 分析搜索结果：
     - 结果数量多 + 近期内容互动高 → 热门话题，需差异化
     - 结果数量少 + 但联想词排名高 → 蓝海机会，优先抢占
  5. 结合时令/节气/热点事件做嫁接
```

**季节性选题日历**：
```
春：花卉图鉴、春季养生、清明民俗
夏：昆虫图鉴、消暑指南、夏日水果
秋：秋叶植物、中秋文化、丰收食材
冬：冬季养生、年货图鉴、春节民俗
```

### 路径 4：跨域迁移法

> 把**其他领域的爆款公式**迁移到图鉴领域

```
操作：
  1. 观察其他类型账号（非图鉴类）的爆款内容
  2. 提取其核心公式（不是具体内容，而是结构/角度）
  3. 用图鉴风格重新包装

示例：
  - 美食博主的"早餐搭配"→ 用图鉴风格做"中国传统早餐图鉴"
  - 心理学博主的"拖延症分析"→ 用解剖图鉴做"拖延症的解剖学"
  - 旅行博主的"必去景点"→ 用图录做"中国古建筑图鉴"
```

## 生成流程

```
Step 1: 确定生成目标
  - 需要多少个选题？（默认 20 个）
  - 侧重哪个 Pillar？（默认全覆盖）
  - 是否结合热点？（默认是）

Step 2: 四条路径并行生成
  - 路径 1 矩阵填充：产出 ~8 个
  - 路径 2 竞品延伸：产出 ~5 个（无 analysis 输入时自动跳过）
  - 路径 3 搜索热点：产出 ~4 个
  - 路径 4 跨域迁移：产出 ~3 个

Step 3: 去重合并
  - 合并语义相近的选题
  - 每个选题生成 3 个标题变体（参考 title-formulas.md）
  - 标注来源路径

Step 4: STEPPS 评分
  - 对每个选题用 STEPPS 六维评分
  - 计算加权总分
  - 按分数排序

Step 5: 分层标记
  - 4.0+ → Hero（爆款级）
  - 3.5-3.9 → Hub（系列级）
  - 3.0-3.4 → Help（常态级）
  - <3.0 → 标记为「待优化」或淘汰

Step 6: 输出选题清单
  - 按评级分组展示
  - 每个选题附带：标题变体、评分、variant 建议、来源路径
  - 写入 backlog 时遵守 `references/config/backlog-schema.md`
```
