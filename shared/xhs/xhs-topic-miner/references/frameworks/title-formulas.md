# 爆款标题公式库

## 数据来源

从「万物图鉴」等同类爆款账号的高赞笔记中提取的标题模式，
结合小红书平台 2024-2026 年运营实践总结。

## 核心原则

1. **数字前置**：含数字的标题点击率比无数字高 36%（BuzzSumo 数据）
2. **情绪钩子**：高唤醒词提升停留（Berger 理论）
3. **悬念缺口**：制造信息缺口，让用户想点开补全
4. **控制长度**：小红书标题 10-20 字最优

## 标题公式矩阵

### 公式 A：数字列举型（最高频，占爆款 60%+）

```
[数字] + [大/种/个/条] + [名词/主题]
```

| 模板 | 示例 | 适用场景 |
|------|------|----------|
| `X大[主题]` | 八大天规、九大凶花 | 经典/权威/庄重话题 |
| `X种[主题]` | 12种饺子馅、百种田园猫 | 分类/品种/多样性 |
| `X个[主题]` | 10个思维、11条戒律 | 方法论/规则/清单 |
| `X步[动作]` | 10步从素颜到精致、5步去黑头 | 流程/教程 |

**高频数字偏好**：
- **8/9/10**：最常见，暗示「完整但不冗长」
- **12**：暗示「全面收录」（12个月、12生肖的文化惯性）
- **4/5**：适合精选型（四大/五大）
- **100+**：适合大全型（百种、百款）
- **奇数比偶数好**：心理学研究显示奇数更有「真实感」

### 公式 B：悬念反转型（第二高频）

```
[看似普通的事物]，[反转/意外结论]
```

| 模板 | 示例 | 情绪机制 |
|------|------|----------|
| `[主题]，第一并不意外` | 人类10大快感排行榜，第一并不意外 | 好奇 → 共鸣 |
| `[主题]，原来是这样` | 元气满满的五果为助，原来是这样 | 好奇 → 恍然大悟 |
| `[主题]，你知道几个？` | 中国十大国粹，你知道几个？ | 挑战 → 社交货币 |
| `[主题]，居然是[结论]` | 最忠诚的狗，居然不是金毛 | 反直觉 → 惊讶 |

### 公式 C：身份/场景绑定型

```
[人群/场景] + [必看/必知/必备] + [主题]
```

| 模板 | 示例 | 触发机制 |
|------|------|----------|
| `[身份]的[数字]个[主题]` | 真男人的四大标准 | 身份认同 |
| `[场景]做这些会[结果]` | 除夕做这些会提升运气 | 场景触发 |
| `[时间]必看的[主题]` | 2026年九大风口 | 时效紧迫 |
| `人生的第一[主题]该怎么选` | 人生的第一只狗狗该怎么选 | 决策焦虑 |

### 公式 D：权威背书型

```
[权威来源] + [数字] + [主题]
```

| 模板 | 示例 | 信任机制 |
|------|------|----------|
| `[名人]的X条[主题]` | 曾国藩11条戒律 | 名人效应 |
| `老祖宗留下的X大[主题]` | 老祖宗留下的九大风水宝地 | 传统权威 |
| `[经典]中的[主题]` | 道家处事之道 | 文化权威 |
| `古人总结的[主题]` | 古人总结的养生智慧 | 历史验证 |

### 公式 E：对比/排行型

```
[主题] + 排行榜/对比/VS
```

| 模板 | 示例 | 传播机制 |
|------|------|----------|
| `[主题]排行榜` | 拆家狗子排行榜 | 争议性 → 评论互动 |
| `[A] vs [B]` | 中医vs西医养生法 | 站队 → 评论互动 |
| `[主题]之最` | 狗狗之最 | 极端值 → 好奇 |

## 标题优化检查清单

对每个生成的标题，检查以下要素：

```
[ ] 包含具体数字（非模糊量词）
[ ] 字数在 10-20 字之间
[ ] 包含至少一个情绪钩子（以下任一）：
    - 敬畏类：天规、圣贤、千年、古法
    - 好奇类：居然、原来、竟然、秘密
    - 实用类：必看、指南、方法、秘诀
    - 趣味类：排行、之最、对比、VS
[ ] 主语明确（不模糊，读者立刻知道讲什么）
[ ] 与图鉴风格契合（适合用复古插画呈现）
[ ] 没有使用平台敏感词/违禁词
```

## 标题 A/B 思维

每个选题生成 3 个标题变体，分别侧重不同 STEPPS 维度：

```yaml
topic: "中国传统茶具"
titles:
  - text: "中国十大经典茶具图鉴"
    formula: A（数字列举）
    stepps_focus: 社交货币（显得有品位）
  - text: "泡茶的灵魂不是茶叶，而是这些器具"
    formula: B（悬念反转）
    stepps_focus: 情绪（反直觉惊讶）
  - text: "老茶客必知的8种传世茶器"
    formula: C（身份绑定）
    stepps_focus: 实用价值（茶客身份触发）
```
