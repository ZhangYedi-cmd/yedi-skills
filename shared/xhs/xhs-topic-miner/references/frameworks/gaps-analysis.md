# GAPS 竞品内容分析框架

## 理论来源

综合 SEMrush / Ahrefs / BuzzSumo 行业实践，以及 BuzzSumo 提出的
「Content Shock」（内容冲击）现象。

## GAPS 四步法

### G - Gap Identification（找空白）

> 竞品**没做**但用户**在搜**的话题

**操作方法**：

1. **搜索补位法**
   - 在小红书搜索框输入竞品账号的核心领域关键词
   - 收集下拉联想词（代表用户高频需求）
   - 对比竞品已发笔记列表，找出未覆盖的联想词
   - 这些就是「内容空白」

2. **评论区挖掘法**
   - 读竞品爆款笔记的评论区
   - 统计用户问得最多的问题
   - 如果这些问题竞品没有单独做过 → 空白

3. **跨竞品交叉法**
   - 竞品 A 做了但竞品 B 没做的话题
   - 多个竞品都做了但角度雷同的话题（有差异化空间）

**输出格式**：
```yaml
gaps:
  - keyword: "中国古代兵器"
    search_volume: "搜索结果 5000+"
    competitor_coverage: "未覆盖"
    opportunity: "HIGH"
  - keyword: "二十四节气图鉴"
    search_volume: "搜索结果 3000+"
    competitor_coverage: "仅1篇，互动低"
    opportunity: "HIGH"
```

### A - Analysis of Top Performers（学高手）

> 竞品做得**最好的**内容，背后是什么规律

**分析维度**：

1. **爆款题材分布**
   ```
   从竞品笔记中提取 TOP 20% 高赞笔记
   按题材聚类，统计每个类目的：
   - 笔记数量
   - 平均点赞
   - 最高点赞
   - 点赞中位数
   ```

2. **标题模式提取**
   ```
   统计爆款标题中的：
   - 数字使用频率和偏好数字（8/9/10/12 最常见）
   - 标题结构模式（"X大XX"、"XX的X个XX"、"XX排行榜"）
   - 情绪词使用（"超绝"、"必看"、"原来"、"居然"）
   - 标题长度分布
   ```

3. **内容形式偏好**
   ```
   图文 vs 视频的互动差异
   系列内容 vs 单篇的互动差异
   不同页数（3/5/8张）的互动差异
   ```

4. **发布节奏**
   ```
   发布频率（日更/周更/不定期）
   发布时间段偏好
   系列内容的间隔节奏
   ```

### P - Positioning & Differentiation（做差异）

> 在学习竞品的基础上，找到**自己的独特角度**

**差异化四象限**：

| | 竞品做过 | 竞品没做过 |
|---|---|---|
| **用户需求强** | 红海话题：需更好的角度/深度/视觉 | 蓝海机会：优先抢占 |
| **用户需求弱** | 低价值：避开 | 低价值：避开 |

**差异化策略**：

1. **深度差异**：竞品做了概览 → 我做深度拆解
2. **角度差异**：竞品从专业角度 → 我从趣味角度
3. **形式差异**：竞品做分类 → 我做对比/排行
4. **组合差异**：竞品 A话题 和 B话题 分开做 → 我做 A×B 的交叉

### S - Systematic Process（系统化）

> 不是做一次竞品分析就完了，而是**持续跟踪**

**执行节奏**：

| 频率 | 动作 |
|------|------|
| 每周 | 快速扫描竞品新发布的笔记，标记值得学习的 |
| 每月 | 完整 GAPS 分析一次，更新选题池 |
| 每季度 | 回顾自己的数据 vs 竞品数据，调整支柱和策略 |

## Content Shock 警示

BuzzSumo 发现的规律——当一个话题从「上升期」进入「过剩期」：
- 发布量增加 → 但平均互动量下降
- 意味着这个话题已经「卷」了

**实操启示**：
- 优先选择**上升期**话题（搜索量增长但内容数量还少）
- 避免**过剩期**话题（大量账号已做过，除非有极强差异化）
- 判断方法：搜索该话题，看结果数量和最新内容的互动水平
