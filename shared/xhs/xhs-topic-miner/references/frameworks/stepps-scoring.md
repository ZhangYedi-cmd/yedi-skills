# STEPPS 传播力评分模型

基于 Jonah Berger（沃顿商学院）《Contagious》及其论文
"What Makes Online Content Viral?"（2012, 被引 1300+）。

## 核心发现

**高唤醒情绪驱动分享**，不是所有好内容都能传播：
- 敬畏感（awe）→ 传播力最强
- 实用价值（practical value）→ 次强
- 愤怒/焦虑（高唤醒负面）→ 也有传播力
- 悲伤/平淡（低唤醒）→ 几乎不传播

正面内容总体优于负面内容，但关键变量是**唤醒度**而非正负。

## 六维评分表

对每个候选选题，按 1-5 分评估以下六个维度：

### S - Social Currency（社交货币）
> 分享这个内容能让我**看起来更好**吗？

| 分数 | 标准 |
|------|------|
| 5 | 分享后显得博学/有品位/见多识广，"你居然知道这个！" |
| 4 | 有一定的「谈资」价值，适合朋友间聊天引用 |
| 3 | 有点意思但不至于主动分享给别人 |
| 2 | 信息比较常见，分享价值低 |
| 1 | 完全没有社交价值，人尽皆知 |

**图鉴类高分信号**：冷知识、反直觉事实、"99%的人不知道"、稀有分类、隐藏规律

### T - Triggers（触发物）
> 用户在日常生活中**多久会想起**这个话题？

| 分数 | 标准 |
|------|------|
| 5 | 高频场景绑定：每天都会遇到（吃饭、通勤、睡觉） |
| 4 | 周频场景：周末、聚餐、购物时会想起 |
| 3 | 月频场景：换季、节日时想起 |
| 2 | 年频场景：只有特定时节才相关 |
| 1 | 无触发场景，纯粹的一次性好奇 |

**图鉴类高分信号**：日常物品的隐藏知识（茶、花、猫、狗）、季节性主题（春花、年货）

### E - Emotion（情绪唤醒）
> 看到这个内容会产生**多强的情绪反应**？

| 分数 | 标准 | 对应情绪 |
|------|------|----------|
| 5 | "哇！太震撼了！" | 敬畏、惊叹、强烈好奇 |
| 4 | "没想到是这样！" | 惊讶、意外、恍然大悟 |
| 3 | "还行，挺有意思" | 轻度好奇、微微一笑 |
| 2 | "知道了" | 平淡认知，无明显情绪 |
| 1 | "嗯…所以呢？" | 无感、无聊 |

**图鉴类高分信号**：「八大天规」→ 敬畏；「九大凶花」→ 好奇+恐惧；「拆家狗排行」→ 趣味共鸣

### P - Public（公共可见性）
> 这个内容被消费/使用的行为**是否容易被别人看到**？

| 分数 | 标准 |
|------|------|
| 5 | 内容本身就是社交话题，适合截图转发、群聊讨论 |
| 4 | 适合做手机壁纸/头像/朋友圈封面，有展示价值 |
| 3 | 适合收藏但不一定展示 |
| 2 | 私人学习型内容，不太适合展示 |
| 1 | 极私密话题，不会被看到 |

**图鉴类高分信号**：视觉精美适合转发、排行榜/清单型适合截图

### P - Practical Value（实用价值）
> 看完之后**能直接用上**吗？

| 分数 | 标准 |
|------|------|
| 5 | 即看即用：食谱、清单、步骤指南 |
| 4 | 短期可用：购物参考、选择指南 |
| 3 | 长期参考：知识沉淀、背景理解 |
| 2 | 轻度有用：扩展视野但不改变行为 |
| 1 | 纯娱乐/猎奇，无实用性 |

**图鉴类高分信号**：「12种饺子馅」「正确去黑头」「人生第一只狗怎么选」

### S - Stories（故事性）
> 能不能用**叙事方式**讲述，让人记住并复述？

| 分数 | 标准 |
|------|------|
| 5 | 天然有戏剧冲突：起承转合、反转、对比 |
| 4 | 有时间线/发展脉络，可以讲成故事 |
| 3 | 可以用类比或拟人手法包装 |
| 2 | 信息列举型，难以叙事化 |
| 1 | 纯数据/纯分类，无故事空间 |

**图鉴类高分信号**：「除夕做这些提升运气」有民俗叙事；「曾国藩11条戒律」有人物故事

## 评分计算

```
总分 = S×0.20 + T×0.10 + E×0.25 + P_public×0.10 + P_practical×0.20 + S_stories×0.15
```

权重说明（基于图鉴类内容特征调优）：
- **情绪唤醒（E）权重最高 0.25**：Berger 研究证明这是传播力第一驱动因素
- **实用价值（P）0.20**：图鉴类内容的核心价值——「收藏 = 有用」
- **社交货币（S）0.20**：「分享显得有文化」是图鉴类内容的天然优势
- **故事性 0.15**：复古图鉴的叙事空间
- **触发物 0.10 + 公共性 0.10**：相对次要但不可忽略

## 评级标准

| 总分 | 评级 | 建议 |
|------|------|------|
| 4.0+ | S 级 | 立即制作，冲爆款 |
| 3.5-3.9 | A 级 | 优先排入计划 |
| 3.0-3.4 | B 级 | 可做，但需优化角度 |
| 2.5-2.9 | C 级 | 暂缓，除非找到更好切入点 |
| <2.5 | D 级 | 放弃或大幅调整 |

## 用「万物图鉴」爆款验证

### "八大天规"（5770 赞）
- S 社交货币: 5（传统智慧，分享显深度）
- T 触发物: 4（为人处世，日常可用）
- E 情绪: 5（敬畏感：古人智慧的庄严感）
- P 公共: 5（金句截图转发率极高）
- P 实用: 4（处世哲学，长期参考）
- S 故事: 4（每条"天规"本身含故事性）
- **总分: 4.55 → S 级** ✓ 符合

### "中华田园猫鉴百种"（3 赞）
- S 社交货币: 3（猫的话题普通）
- T 触发物: 4（养猫人天天看猫）
- E 情绪: 2（品种列举，唤醒度低）
- P 公共: 3（猫主人会看但未必转发）
- P 实用: 3（认猫用，但不紧急）
- S 故事: 2（分类列举，无叙事）
- **总分: 2.75 → C 级** ✓ 符合（标题也缺乏情绪钩子）
