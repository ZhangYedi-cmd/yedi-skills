# Outline Template 大纲模板

## 格式

```yaml
---
strategy: a
name: 百科全书型
variant: natural-history
orientation: portrait
image_count: 10
cover_archetype: cover-B  # ⭐ 必填：从 cover-A/B/C/D/E/F 中选择
content_layout: single-subject-plate  # ⭐ 内容页版型
---

## P1 封面
**Type**: cover | **Cover Archetype**: cover-B (多人群像)
**标题**: 龙生九子
**副标题**: Nine Sons of the Dragon · Chinese Mythology Encyclopedia
**角标左**: 「图鉴」
**角标右**: 「龙族」
**封面设计**: 9个龙子角色错落排列，中央最大的是龙王（非对称群像），
  每个龙子持有/伴随其代表器物，环境有水墨山水暗景
**信息密度**: 最高

## P2-P10 内容页（一页一龙子）

### P2 - 囚牛
**Type**: content | **Layout**: single-subject-plate
**角标左**: 「龙子第一」
**角标右**: 「好音律」
**标题**: 囚牛

```

## 三种策略

| 策略 | 侧重 | 结构 | 页数 |
|------|------|------|------|
| A 百科全书 | 广度 | 封面 → 每项一页(×N) → [总结] | 1+N [+1] |
| B 深度解剖 | 深度 | 封面 → 多维度拆解(×M) → 总结 | 1+M+1 |
| C 场景叙事 | 趣味 | 封面 → 场景推进(×M) → 金句 | 1+M+1 |

### 策略 A：一页一主题（列表类内容首选 ⭐）
```
P1: 封面（Cover Archetype 选择）
P2-P(N+1): 每页一个主题/条目/品种（single-subject-plate）
P(N+2): [可选] 总结页/速查表/对比汇总
```
**适用**：龙生九子、八大天规、12种饺子馅、十大国粹、N大规律…
**禁止**：将多个条目合并到同一页（如"上三子/中三子/下三子"）

### 策略 B：多维度深度拆解
```
P1: 封面（Cover Archetype 选择）
P2-P(M+1): 每页一个分析维度（annotated / knowledge-split）
P(M+2): 总结/数据面板
```
**适用**：单品分析、命理体系、某一类文化的多角度解读

### 策略 C：场景叙事推进
```
P1: 封面（Cover Archetype 选择）
P2-P(M+1): 按时间/因果/场景递进（sequential / knowledge-split）
P(M+2): 金句/总结
```
**适用**：过程指南、行为解析、历史演变

## 每页检查清单

### 封面检查
- [ ] Cover Archetype 与内容匹配（非默认 center-radial）
- [ ] 大标题+英文副标题+角标印章齐全
- [ ] 画面有叙事感/吸引力，元素自然排布（非对称圆环）
- [ ] 信息密度最高

### 内容页检查
- [ ] ⭐ 每页只聚焦一个主题/条目
- [ ] 主体插画占页面40-50%，详细有细节
- [ ] ≥4 个标注/标签
- [ ] ≥1 个知识框（带边框的文字块）
- [ ] 底部有总结框或金句
- [ ] 角标印章：左系列序号 + 右特质词
