# Analysis Framework 主题分析框架

## 分析维度

### 1. 核心对象
主体是什么？属什么大类？具象还是抽象？

### 2. 信息类型 → Variant
| 信号词 | Variant |
|--------|---------|
| 品种/种类/分类/大全 | natural-history |
| 结构/原理/分析/拆解 | anatomy |
| 搭配/配什么/绝配 | pairing |
| 混合/融合/对比/VS | fusion |
| 步骤/流程/过程 | process |
| 工具/器具/收藏 | catalog |

### 3. 内容结构类型 → 页数规划 ⭐ 新增

> **核心原则：列表类内容默认「一页一主题」**

| 结构类型 | 判断信号 | 默认页数 | 每页内容 |
|----------|---------|---------|---------|
| **列表型** | "N种…"、"N大…"、"N个…" | 1封面 + N内容页 | 每页聚焦一个条目，深度展开 |
| **维度型** | "…的特征/结构/原理" | 1封面 + 3-5内容页 | 每页一个分析维度 |
| **流程型** | "…步骤/过程/怎么做" | 1封面 + 步骤数内容页 | 每页一个关键步骤 |
| **对比型** | "A vs B"、"选哪个" | 1封面 + 2-4内容页 | 每页一个对比维度 |

**列表型详细规则：**
- 龙生九子(9个) → 1封面 + 9内容页 = 10张
- 八大天规(8条) → 1封面 + 8内容页 = 9张
- 12种饺子馅(12种) → 1封面 + 12内容页 + 可选总结页 = 13-14张
- 小红书限制：最多18张图。如 N>16，可适当合并（如将相似项2合1）

**⚠️ 禁止**：将列表型内容按3合1、2合1分组到同一页（如"上三子/中三子"）。
这会导致每个条目展示空间不足，信息密度降低。

### 4. 封面版型 → Cover Archetype ⭐ 新增

根据内容特点自动选择封面，**禁止全部默认 center-radial**：

| 内容信号 | 推荐 Cover | 理由 |
|----------|-----------|------|
| N种品种/物品 + 可以用"容器"展示 | cover-A 物品环绕 | 容器聚焦，品种散落 |
| N个人物/角色/规则 | cover-B 多人群像 | 人物群像叙事 |
| 单品深度解析（单个植物/动物/物品） | cover-C 标本解剖 | 单品放大+标注 |
| 步骤/流程/变化/对比 | cover-D 流程变换 | 前后转变可视化 |
| 按维度/人群分类的选择指南 | cover-E 分区分类 | 分区对比易读 |
| 多主题合集/系列总览 | cover-F 场景多格 | 多格展示丰富度 |

> 详细定义见 `references/layouts/portrait-layouts.md` Part 1

### 5. 调性
严肃科普 / 幽默反差 / 温馨怀旧 / 实用指南 / 传统智慧

### 6. 幽默/金句潜力
| 反差类型 | 示例 |
|----------|------|
| 古今对比 | "千年规矩，今天依然灵验" |
| 反差萌 | "看似最凶的睚眦，其实只是个武器装饰" |
| 数据反差 | "点赞5814 → 这条天规确实管用" |

## 输出格式
```markdown
# 主题分析：[主题]

## 核心对象
[描述]

## 内容结构
- 结构类型：列表型 / 维度型 / 流程型 / 对比型
- 条目数量：N 个
- 每页内容：[描述每页聚焦什么]

## 推荐方案
- Variant：[变体名]
- 封面版型：[cover-A/B/C/D/E/F] — [理由]
- 内容页版型：[single-subject-plate / annotated / knowledge-split]
- 页数：1封面 + N内容页 [+ 可选总结页] = X张

## 封面设计概念
[2-3句描述封面画面，具体到主体、构图、氛围]

## 标题建议(×3)
## 金句/幽默切入点
```
