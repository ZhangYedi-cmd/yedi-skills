# Color Palettes 色彩体系

## 核心色板（共享）— 对标万物图鉴实测色调

| 角色 | 色值 | 用途 |
|------|------|------|
| 纸张主色 | #F0E0C0 仿宣纸米黄, #E8D5B0 暖褐底, #EDE0C8 淡褐 | 背景（比纯羊皮纸更暖、更接近中国宣纸） |
| 墨色主调 | #3A2A1A 深棕墨, #5C3D2E 棕褐, #8B6914 暖褐 | 文字、线条、边框 |
| 结构色 | #C0392B 朱砂红, #922B21 深朱红 | 角标印章、重点标题、✓✗ 图标 |
| 知识框色 | #D4A853 琥珀黄, #FFBF00 亮琥珀 | 知识框边线、编号底色 |
| 自然插画 | #4A7C59 深翠绿, #2E6B3E 墨绿, #8B1A1A 深红 | 植物/山水插画点缀（高于整体饱和度） |
| 笔记框底 | #FAF3E8 极淡米白 | 知识块内部填色，与底纸区分 |
| 禁用 | 霓虹, 荧光, 纯黑大面积, 冷蓝, 冷白 | — |

> **关键区别**：博主用的不是西方博物馆羊皮纸调，而是**中国宣纸/旧书纸调**——底色偏米白偏暖，文字用深棕墨（非纯黑），植物/自然图画局部饱和度高（翠绿、深红），但整体背景保持低饱和。

## Prompt 色彩模板
```
Color palette: warm Chinese xuan paper tone. Background: aged yellowish-white
rice paper (#F0E0C0 to #E8D5B0), warm and matte. Ink colors: deep sepia brown
(#3A2A1A) for text and lines. Accents: cinnabar red (#C0392B) for corner stamps
and emphasis. Natural illustrations (plants, animals) use richer, more saturated
greens and reds as contrast against the muted background.
AVOID: neon, fluorescent, pure black fills, cold blue/white, Western parchment
yellow-green tone.
```

## 变体色调偏向
- natural-history: 暖米底 + 翠绿/深红自然色（植物饱和度高）
- anatomy: 暖米底 + 朱砂标注线 + 琥珀知识框
- pairing: 暖色底 + 食物本色点缀
- fusion: A/B各自色系 + 融合中间调
- process: 琥珀编号色 + 朱红箭头
- catalog: 旧金边框 + 深棕分类标签

## 角标印章色
朱砂红方形印章 `#C0392B`，填色文字用白或极淡米（非纯白）。
印章字体：黑体或仿宋，2-4个汉字（如「图鉴」「天规」「宝地」「百科」）。
