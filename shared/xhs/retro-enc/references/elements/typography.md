# Typography 文字系统 — 对标万物图鉴

## 文字层级
| 层级 | 风格 | 示例 |
|------|------|------|
| H1 大标题 | 粗黑体/粗宋，超大尺寸，居中或左对齐 | 师不顺路 / 「八大天规」 |
| H2 主题副标题 | 中等宋体，灰褐色 | 中国传统八大天规之首 |
| H3 英文副标题 | 衬线英文，小于H1，点号隔开 | Eight Heavenly Principles · Ancient Chinese Wisdom |
| 页面分类行 | 小字说明，多项用｜分隔 | 地势高爽｜排水通畅｜阳光充足 |
| 知识块标题 | 粗体中文 + 编号 | ①尊重隐私 / ②避免反应 |
| 知识点标注 | 手写感细字，带标注线 | 耳尖毛簇、排水通畅 |
| 强调标注 | ✓（绿色）/ ✗（红色）+ 说明文字 | ✓ 三顾茅庐，技艺受重 / ✗ 主动揽活，失了身份 |
| 金句/点评框 | 圆角矩形框，楷体斜体 | "真正的高手，从不自降身份…" |
| 署名 | 小字底部 | 作者：@万物图鉴 |

## ❌ 已废弃：伪拉丁学名
博主风格中**无任何西方伪拉丁学名**。用以下中式系统替代：
- 右上/左上角：**红色方形角标印章**（「图鉴」「天规」「宝地」「百科」等）
- 左上/右上角：**类别小徽章**（「匠人风骨」「悬壶济世」等 2-4 字主题词）
- 页眉处可加：主题系列序号（天规 第一 / 天规 第二）

## 标题模板（封面页）
```
大标题（超大）：[核心知识词] 或 「[主题]」
副标题（中等）：[具体说明短语，如"中国传统八大天规之首"]
英文副标题（小）：[English Theme] · [Type Keywords]
左上角印章：[系列类别，如"图鉴"]
右上角印章：[主题词，如"天规"]
```

## 内容页标题模板
```
左上角分类标签（红色方块）："天规第一" / "天规第二" ...
右上角主题词（红色方块）："匠人风骨" / "悬壶济世" ...
页面主标题（超大，占顶部30%）：核心规则名称（如"师不顺路"）
副主题（中等）：[规则说明，如"中国传统八大天规之首"]
下方一行分类说明：[属性标签]｜[属性标签]｜[属性标签]
```

## Prompt 文字指令
直接在 prompt 中写出完整中文内容和位置。尽量让 AI 渲染关键文字，
尤其是大标题和角标印章（这两个位置最容易被正确渲染）。
知识块内的细节文字注明位置即可，具体文字内容由后期处理补充。
