# 万物图鉴内容页 — 视觉 DNA 规范 v1.0

> 继承 wanwu-cover v2.0 的核心视觉基因，在此基础上定义内容页专属视觉元素。
> 所有数据来自对 @万物图鉴 实际内容页的逆向视觉分析（子鼠/丑牛/虎/马/武术等）。

---

## 继承自 wanwu-cover v2.0（不再重复详述）

以下元素与封面完全一致，详见 `wanwu-cover/references/visual-dna.md`：

- **渲染风格**：丝滑数字插画，85-90% 写实度
- **色彩体系**：宣纸底 #E8D5B0、主墨色、朱砂红、点缀金、辅助绿
- **饱和度**：70-85%
- **双边框系统**：外框 ~3% + 内框 ~7-8% + 呼吸带
- **印章系统**：角标印章 + 散布印章
- **文字基础**：毛笔书法标题 + 衬线英文
- **微观细节**：金属星芒、玉石光泽、液体透光等
- **装饰系统**：祥云、做旧纹理、金色元素
- **绝对禁用**：维多利亚边框、Anime、CGI、霓虹色等

## 内容页专属视觉元素

### 1. 知识模块框架系统

内容页的核心区别：**信息被组织为结构化的知识模块**。

#### 1.1 区域标题框

```
┌─────────────────────┐
│  生肖文化象征         │   ← 白底深褐色边框，标题文字深褐加粗
└─────────────────────┘
```

- 位置：左栏/右栏顶部
- 样式：圆角矩形边框，线条颜色 #8B6914，内部微淡底色
- 文字：深褐色 #3A2A1A，加粗宋体/楷体
- 尺寸：约画面宽度 20-25%

#### 1.2 编号标题

```
① 十二生肖排序
② 民间寓意图解
③ 民俗谚语
④ 时辰图解
```

- 编号用圆圈数字 ①②③④（非括号，非阿拉伯数字）
- 标题文字加粗，深褐色
- 编号后紧跟标题，无多余间距

#### 1.3 知识卡片（叙事章节布局专用）

```
┌──────────┐
│ 【渊源】  │
│ [小插图]  │
│ 说明文字  │
└──────────┘
```

- 标题用中文黑方括号【】
- 卡片有淡边框或无框（靠分组间距区隔）
- 内含小插图 + 1-3 行说明文字

### 2. 标注系统

#### 2.1 解剖标注线

```
主体插图 ─────→ 门齿终生生长
         ─────→ 触须感环境
         ─────→ 善于储粮
```

- 细线从主体各部位引出，指向标注文字
- 线条：1px 深褐色 #5C3D2E，可带箭头或圆点端点
- 文字：小号楷体，深褐色
- 常用于 anatomy-spread 布局

#### 2.2 标签（Tag Labels）

```
┌─────┐  ┌─────┐  ┌─────┐
│ 草食 │  │ 群居 │  │ 农耕 │
└─────┘  └─────┘  └─────┘
```

- 小圆角矩形，浅底色 + 深褐色细边框
- 文字 2-4 字，居中
- 常紧贴在小插图旁边，作为快速索引关键词
- 也可用于特征标记（力量、耐力、温顺、勤劳）

#### 2.3 特征列表

```
鼠类特征
✓ 嗅觉灵敏
✓ 繁殖能力强
✓ 适应环境能力强
✓ 善于打洞
✓ 记忆路径能力强
```

- 红色/深褐色对勾 ✓ 或 ✔
- 每行一个特征，紧凑排列
- 标题加粗，特征列表正常字重

### 3. 微缩插图系统

#### 3.1 场景插图（Vignette）

每个知识点配一个小型场景图：

```
┌──────────┐
│  [小场景]  │   ← 如：鼠在粮仓觅食 / 牛在草地进食 / 小鼠夜行图
│           │
└──────────┘
储粮本能         ← 标题/说明
```

- 尺寸：约画面的 8-12% 宽
- 风格：与主体一致的丝滑数字插画，但更简化
- 有淡边框或无框（靠阴影/间距区隔）
- 每个 vignette 是一个自包含的小故事

#### 3.2 微观放大圈

```
    ╭──────╮
    │ 鼠毛  │   ← 圆形放大镜效果
    │ 放大图 │
    ╰──────╯
```

- 圆形，带细边框
- 展示微观细节：毛发纹理、蹄结构、鳞片、纤维
- 位置：通常在主体附近，用细线连接到放大位置
- 每页 1-3 个

#### 3.3 结构简图

```
    耳朵
     ↓
头部 → [简笔牛图] ← 角
     ↓
    蹄─→ 尾
```

- 简化的结构/解剖示意图
- 线条稍粗，标注清晰
- 位置：底部区域
- 风格：比主体更简化，接近白描线稿

### 4. 趣味/互动元素

#### 4.1 角色引言框

```
┌─────────────────────────────────────────┐
│ 老鼠：在人类文化里，我可能是偷粮高手，  │
│ 但在生肖里，我却是第一名。              │
│ 聪明一点，总能抢到起跑线。              │
└─────────────────────────────────────────┘
```

- 仿对话气泡或卷轴边框
- 第一人称，拟人化趣味发言
- 标题（角色名）用红色/加粗
- 位置：中下部，靠近主体
- 增加亲和力和社交分享性

#### 4.2 趣味评论框（comprehensive-topic 专用）

```
╔═════════════════════════════════════╗
║ 武术：中国唯一让打人还能被称为        ║
║ "传统文化传承者"的运动…              ║
╚═════════════════════════════════════╝
```

- 仿古告示牌/木匾/卷轴样式
- 幽默短评，增加传播性
- 位置：底部区域

#### 4.3 寓意/象征列表

```
停留环境寓意
鼠入粮仓 → 富足
鼠入厨房 → 粮丰
鼠抱谷粒 → 丰收
鼠守仓门 → 财富
```

- 箭头 → 连接现象与寓意
- 紧凑两列布局
- 增加文化深度

### 5. 底部信息区

#### 5.1 属性条（anatomy-spread 专用）

```
生肖属性
生肖: 鼠    五行: 水    方方: 北    时辰: 子时 (23:00-01:00)
```

- 键值对横排，中点或空格分隔
- 位于底部左侧
- 宋体小号

#### 5.2 文化寓意图标行

```
⊕聪明  ⊕机敏  ⊕财富  ⊕机遇  ⊕灵活
```

- 小圆形图标 + 下方 2 字关键词
- 3-6 个一行排列
- 位于底部右侧

#### 5.3 解说文段（narrative-chapter 专用）

```
山君者，虎之雅称也。《说文解字》云: "虎，山兽之君也。"
虎为百兽之王，统领山林，故得"山君"之名。古人敬畏，
常以"大虫"讳称之。
```

- 底部占约 10-12% 画面高度
- 宋体小号，深褐色
- 有细边框包围
- 在 narrative-chapter 布局中替代属性条

#### 5.4 底部印章条

```
[博物志]  ⊙  [古今图鉴]   ← 底部两端各一红色印章
          [寅]             ← 中央圆形地支符号
```

- 2 个矩形印章分列两端
- 中间可选圆形地支/标志符号
- 位于外框区域底部

### 6. 内容页色彩补充

在封面色彩体系基础上，内容页增加以下色彩用途：

| 用途 | 色值 | 说明 |
|------|------|------|
| 标签底色 | `#F5E6C8` 50% | 标签内部淡底色 |
| 标签边框 | `#8B6914` | 与边框同色 |
| 编号文字 | `#C0392B` | 部分编号用朱砂红 |
| 标注线 | `#5C3D2E` 70% | 解剖标注用半透明深褐 |
| 知识卡背景 | `#F5EED8` 30% | 极淡底色区分模块 |
| 夜景底色 | `#1A1A3A` ~ `#2A2A4A` | 夜间场景 vignette 专用 |
| 地下/洞穴色 | `#8B7355` ~ `#A0926B` | 地洞剖面场景 |

### 7. 画布规格

与封面一致：

```
竖版（主流）：1792 × 2400 px（3:4）
横版：1920 × 1080 px（16:9）
```

**内容页信息密度要求**：
- 封面：视觉冲击力优先，信息密度中等
- 内容页：信息密度优先，视觉冲击力次之
- 内容页的文字面积占比 ≈ 25-35%（封面约 10-15%）
- 内容页的小插图数量 ≈ 8-20 个（封面约 3-10 个）
