# 知识模块框架系统

内容页的核心区别：**信息被组织为结构化的知识模块**。

## 区域标题框

```
┌─────────────────────┐
│  生肖文化象征         │   ← 白底深褐色边框，标题文字深褐加粗
└─────────────────────┘
```

- 位置：左栏/右栏顶部
- 样式：圆角矩形边框，线条颜色 #8B6914，内部微淡底色
- 文字：深褐色 #3A2A1A，加粗宋体/楷体
- 尺寸：约画面宽度 20-25%

## 编号标题

```
① 十二生肖排序
② 民间寓意图解
③ 民俗谚语
④ 时辰图解
```

- 编号用圆圈数字 ①②③④（非括号，非阿拉伯数字）
- 标题文字加粗，深褐色
- 编号后紧跟标题，无多余间距

## 知识卡片（叙事章节布局专用）

```
┌──────────┐
│ 【渊源】  │
│ [小插图]  │
│ 说明文字  │
└──────────┘
```

- 标题用中文黑方括号【】
- 卡片有淡边框或无框（靠分组间距区隔）
- 内含小插图 + 1-3 行说明文字
