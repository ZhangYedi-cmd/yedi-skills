# 趣味/互动元素 & 底部信息区

---

## 趣味/互动元素

### 角色引言框

```
┌─────────────────────────────────────────┐
│ 老鼠：在人类文化里，我可能是偷粮高手，  │
│ 但在生肖里，我却是第一名。              │
│ 聪明一点，总能抢到起跑线。              │
└─────────────────────────────────────────┘
```

- 仿对话气泡或卷轴边框
- 第一人称，拟人化趣味发言
- 标题（角色名）用红色/加粗
- 位置：中下部，靠近主体
- 增加亲和力和社交分享性

### 趣味评论框（comprehensive-topic 专用）

```
╔═════════════════════════════════════╗
║ 武术：中国唯一让打人还能被称为        ║
║ "传统文化传承者"的运动…              ║
╚═════════════════════════════════════╝
```

- 仿古告示牌/木匾/卷轴样式
- 幽默短评，增加传播性
- 位置：底部区域

### 寓意/象征列表

```
停留环境寓意
鼠入粮仓 → 富足
鼠入厨房 → 粮丰
鼠抱谷粒 → 丰收
鼠守仓门 → 财富
```

- 箭头 → 连接现象与寓意
- 紧凑两列布局
- 增加文化深度

## 底部信息区

### 属性条（anatomy-spread 专用）

```
生肖属性
生肖: 鼠    五行: 水    方方: 北    时辰: 子时 (23:00-01:00)
```

- 键值对横排，中点或空格分隔
- 位于底部左侧
- 宋体小号

### 文化寓意图标行

```
⊕聪明  ⊕机敏  ⊕财富  ⊕机遇  ⊕灵活
```

- 小圆形图标 + 下方 2 字关键词
- 3-6 个一行排列
- 位于底部右侧

### 解说文段（narrative-chapter 专用）

```
山君者，虎之雅称也。《说文解字》云: "虎，山兽之君也。"
虎为百兽之王，统领山林，故得"山君"之名。古人敬畏，
常以"大虫"讳称之。
```

- 底部占约 10-12% 画面高度
- 宋体小号，深褐色
- 有细边框包围
- 在 narrative-chapter 布局中替代属性条

### 底部印章条

```
[博物志]  ⊙  [古今图鉴]   ← 底部两端各一红色印章
          [寅]             ← 中央圆形地支符号
```

- 2 个矩形印章分列两端
- 中间可选圆形地支/标志符号
- 位于外框区域底部

## 内容页色彩补充

在封面色彩体系基础上，内容页增加以下色彩用途：

| 用途 | 色值 | 说明 |
|------|------|------|
| 标签底色 | `#F5E6C8` 50% | 标签内部淡底色 |
| 标签边框 | `#8B6914` | 与边框同色 |
| 编号文字 | `#C0392B` | 部分编号用朱砂红 |
| 标注线 | `#5C3D2E` 70% | 解剖标注用半透明深褐 |
| 知识卡背景 | `#F5EED8` 30% | 极淡底色区分模块 |
| 夜景底色 | `#1A1A3A` ~ `#2A2A4A` | 夜间场景 vignette 专用 |
| 地下/洞穴色 | `#8B7355` ~ `#A0926B` | 地洞剖面场景 |

## 画布规格

与封面一致：

```
竖版（主流）：1792 × 2400 px（3:4）
横版：1920 × 1080 px（16:9）
```

**内容页信息密度要求**：
- 封面：视觉冲击力优先，信息密度中等
- 内容页：信息密度优先，视觉冲击力次之
- 内容页的文字面积占比 ≈ 25-35%（封面约 10-15%）
- 内容页的小插图数量 ≈ 8-20 个（封面约 3-10 个）
