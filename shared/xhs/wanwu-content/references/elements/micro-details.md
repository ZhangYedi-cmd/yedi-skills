# 微观细节系统

## 总原则

```
每个金属表面 → 高光线 + 星芒闪烁（✦）
每个光滑表面 → 弧面高光反射
每个透明/半透明材质 → 光线穿透效果
每个散落小物件 → 微小投影
每个布料 → 织纹/丝线方向性反光
```

## 材质细节清单

| 材质 | 微观细节要求 |
|------|------------|
| **银针/金属** | 沿长度高光线 + 针尖4点星芒（✦）+ 铜金色螺旋线柄 |
| **围棋子** | 黑子：深玉石光泽 + 单亮点。白子：温润半透明 + 柔和rim光 |
| **茶汤液柱** | 半透明 + 背光琥珀色透光 + 液面涟漪 + 蒸汽边缘透光 |
| **刺绣丝线** | 方向性光泽（不同角度反光不同）+ 绣框木纹清晰 |
| **剪纸** | 纸张厚度感 + 切边微卷 + 底部投影 |
| **瓷器** | 多处弧面高光（口沿/瓶身/底部）+ 釉下花纹有深度感 |
| **布料/丝绸** | 缎面光泽 + 织纹走向 + 柔和褶皱阴影 |
| **人参/草药** | 根须细节 + 湿润蜡质表面光泽 |
| **毛笔** | 笔毫根根可辨 + 笔尖墨水饱满欲滴 |
| **铜钱** | 铜绿氧化质感 + 凸起字纹 + 微小投影 |
| **花瓣** | 正反面区分 + 叶脉纹路 + 半透明边缘 |
