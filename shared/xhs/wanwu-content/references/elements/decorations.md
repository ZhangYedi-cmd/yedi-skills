# 装饰系统 + 画布规格 + 禁用清单

> Prompt 拼装块见 `workflows/prompt-assembly.md` Module 7 和 Module 9。

## 装饰元素

### 祥云/云纹
极淡（10-20%），四角+主体间过渡，不抢主体。

### 做旧纹理
宣纸纤维质感 + 极淡茶渍斑（15-25%）+ 轻微暗角 vignette。
注意：**轻度做旧**，不能像破旧纸张。

### 金色元素
元宝、铜钱、金色光晕 — 吉祥/财富主题增加。

### 散落元素
与主题相关的小物件（棋子、墨滴、花瓣、茶叶、铜钱），3-8 个，很小（1-3%），有微小投影。

### 背景深度
极淡建筑/山水剪影（故宫/山脊）15-20% 透明度，增加文化氛围。

---

## 画布规格

### 竖版（主流）
```
尺寸：1792 × 2400 px（3:4）
安全区：外框线内（距边 3%）
内容区：内框线内（距边 7-8%）
```

### 横版
```
尺寸：1920 × 1080 px（16:9）或 1660 × 1242 px（4:3）
```

---

## 绝对禁用清单

```
- 维多利亚/洛可可/巴洛克西式边框
- Anime/漫画/3D CGI
- 高饱和霓虹色/荧光色
- 伪拉丁学名文字
- 照片写实人脸
- 纯白色背景
- 现代无衬线字体标题
- 渐变色背景
- 平涂工笔线稿风（太素描感、太水彩淡薄）
- 静态博物馆标本陈列感
- 粗糙手绘感/可见铅笔线条
```
