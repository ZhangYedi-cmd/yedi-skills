# 标注系统

## 解剖标注线

```
主体插图 ─────→ 门齿终生生长
         ─────→ 触须感环境
         ─────→ 善于储粮
```

- 细线从主体各部位引出，指向标注文字
- 线条：1px 深褐色 #5C3D2E，可带箭头或圆点端点
- 文字：小号楷体，深褐色
- 常用于 anatomy-spread 布局

## 标签（Tag Labels）

```
┌─────┐  ┌─────┐  ┌─────┐
│ 草食 │  │ 群居 │  │ 农耕 │
└─────┘  └─────┘  └─────┘
```

- 小圆角矩形，浅底色 + 深褐色细边框
- 文字 2-4 字，居中
- 常紧贴在小插图旁边，作为快速索引关键词
- 也可用于特征标记（力量、耐力、温顺、勤劳）

## 特征列表

```
鼠类特征
✓ 嗅觉灵敏
✓ 繁殖能力强
✓ 适应环境能力强
✓ 善于打洞
✓ 记忆路径能力强
```

- 红色/深褐色对勾 ✓ 或 ✔
- 每行一个特征，紧凑排列
- 标题加粗，特征列表正常字重
