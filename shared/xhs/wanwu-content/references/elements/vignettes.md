# 微缩插图系统

## 场景插图（Vignette）

每个知识点配一个小型场景图：

```
┌──────────┐
│  [小场景]  │   ← 如：鼠在粮仓觅食 / 牛在草地进食 / 小鼠夜行图
│           │
└──────────┘
储粮本能         ← 标题/说明
```

- 尺寸：约画面的 8-12% 宽
- 风格：与主体一致的丝滑数字插画，但更简化
- 有淡边框或无框（靠阴影/间距区隔）
- 每个 vignette 是一个自包含的小故事

## 微观放大圈

```
    ╭──────╮
    │ 鼠毛  │   ← 圆形放大镜效果
    │ 放大图 │
    ╰──────╯
```

- 圆形，带细边框
- 展示微观细节：毛发纹理、蹄结构、鳞片、纤维
- 位置：通常在主体附近，用细线连接到放大位置
- 每页 1-3 个

## 结构简图

```
    耳朵
     ↓
头部 → [简笔牛图] ← 角
     ↓
    蹄─→ 尾
```

- 简化的结构/解剖示意图
- 线条稍粗，标注清晰
- 位置：底部区域
- 风格：比主体更简化，接近白描线稿
