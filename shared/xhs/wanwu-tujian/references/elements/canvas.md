# Canvas 画布规格

## Aspect Ratios
| 名称 | 比例 | 像素 | 场景 |
|------|------|------|------|
| portrait-xhs | 3:4 | 1792×2400 | 小红书竖版（**首选**，对标万物图鉴实际上传尺寸） |
| portrait-9-16 | 9:16 | 1080×1920 | 小红书竖版（备用） |
| portrait-3-4 | 3:4 | 1242×1660 | 小红书方竖版（备用） |
| landscape-16-9 | 16:9 | 1920×1080 | 公众号/桌面横版 |
| landscape-4-3 | 4:3 | 1660×1242 | 横版标准 |

## Safe Zones
- 顶部 15%：标题区（大标题 + 英文副标题 + 左上/右上角标印章）
- 中部 70%：核心插画 + 知识区块 + 标注线
- 底部 10%：署名区（`作者：@知渡`，小红书标题栏会遮挡，避免放关键信息）
- 右上角：避开点赞按钮区域；左上/右上角是角标印章的惯用位置
