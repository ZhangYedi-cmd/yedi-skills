# 万物图鉴 内容分析框架 — v3.1

深度分析框架，融合小红书平台特性与万物图鉴垂直领域信号。

## 目的

在生成图鉴组图前，全面分析源材料以：
- 最大化 Hook 吸引力和翻页动力
- 识别收藏/分享触发点
- 规划视觉叙事弧线
- 自动匹配最优构图模式和写实度

## 平台特性（小红书）

- **Hook Power**: 封面图决定 90% 的互动
- **Swipe Motivation**: 每张图必须驱动翻页
- **Save Value**: 值得收藏备查的内容
- **Share Triggers**: 驱动分享的情感共鸣

## 分析维度

### 1. 内容类型分类（万物图鉴5类）

| 类型 | 特征 | 推荐构图 | 互动潜力 |

### 2. Hook 分析（爆款标题潜力）

**万物图鉴专属 Hook 模式**：
- **权威古典钩**: 借用古典权威感 → "老祖宗的智慧"、"古人总结"、"千年传承"
- **数量钩**: 数字+大全/合集 → "八大天规"、"九不争"、"十大国粹"
- **秘密钩**: 少有人知的知识 → "很少人知道的..."、"99%的人不知道"

**通用 Hook 类型**：
- **数字钩子**: "5个方法", "3分钟学会", "99%的人不知道"
- **痛点钩子**: "踩过的坑", "后悔没早知道", "别再..."
- **好奇钩子**: "原来...", "竟然...", "没想到..."
- **利益钩子**: "省钱", "变美", "效率翻倍"
- **身份钩子**: "打工人必看", "学生党", "新手妈妈"

**评分标准**：
- ⭐⭐⭐⭐⭐ (5/5): 多重钩子叠加 + 古典权威感
- ⭐⭐⭐⭐ (4/5): 清晰钩子，可优化
- ⭐⭐⭐ (3/5): 基础钩子，需加强
- ⭐⭐ (2/5): 弱钩子，需大幅改进
- ⭐ (1/5): 无明显钩子

### 4. 互动潜力（四维评估）

**收藏价值**:
- 是参考资料/百科？ ✓ 高收藏
- 是清单/大全？ ✓ 高收藏
- 是教程/步骤？ ✓ 高收藏
- 是时效性新闻？ ✗ 低收藏

**分享冲动**:
- "这个大全太全了必须分享" → 实用分享
- "老祖宗的智慧太有道理了" → 认同分享
- "给爸妈/朋友看看" → 关系分享
- "涨知识了" → 知识分享

**评论诱导**:
- "你知道几个？"
- "你是哪种类型？"
- "还有什么要补充的？"
- "你最认同哪一条？"

**互动设计**:
- 投票: "最实用的是哪个？"
- 挑战: "你能做到几条？"
- @好友: "@你那个需要看这个的朋友"

### 7. 翻页流设计（Swipe Flow）

| 位置 | 目的 | Hook 策略 |
|------|------|-----------|
| **封面 (Cover)** | 停住滑动 | 最强视觉冲击 + 权威古典感标题 + dense-cluster 布局 |
| **铺垫 (Setup)** | 建立语境 | 为什么要了解？共鸣/好奇 |
| **核心 (Core)** | 交付价值 | 每页1-2个要点，高信息密度 |
| **收获 (Payoff)** | 实践收获 | 可执行的建议/总结 |
| **结尾 (Ending)** | 驱动行动 | 互动引导 + 金句 |

**翻页驱动**：
- 每张图末尾设置下一页的钩子
- 编号递进："第3个最重要"
- 悬念递进："最后一个很少人知道"
- 信息缺口：需要翻页才能看到完整内容
