# Query 工作流

## 使用场景

用自然语言查询知识库，获取带引用的结构化回答。适用于：
- 跨笔记综合检索（"关于 X 的观点有哪些？"）
- 概念定义查询（"什么是 Y？"）
- 关系梳理（"X 和 Y 有什么关系？"）
- 追溯来源（"我在哪里读到过关于 Z 的内容？"）

## 触发命令

```bash
/knowledge-forge query "问题"
```

也可在对话中自然触发，如"帮我查一下知识库里关于 XX 的内容"。

## 依赖工具

| 工具 | 用途 | 必须？ |
|------|------|--------|
| 文件系统读取 | 扫描 40-Atoms/ 和 00-Inbox/ | 是 |
| Glob | 文件名匹配 | 是 |
| Grep | 正文内容搜索 | 是 |

无外部依赖，纯本地处理。

## 前置条件

- `40-Atoms/` 中有笔记
- 如果库中无内容，提示: "知识库还是空的，先用 `/knowledge-forge ingest <url>` 摄入一些内容吧"

---

## Phase 1: 关键词提取

**执行者**: AI 处理用户输入

**目标**: 从自然语言问题中提取 2-4 个核心搜索词

**规则**:
- 提取名词、专有名词、技术术语
- 中英文都提取（知识库可能混合语言）
- 去掉停用词（"什么是"、"如何"、"关于"等）
- 优先提取具体概念而非抽象词

**示例**:
```
输入: "关于 OpenClaw 的可及性问题，知识库里有什么？"
提取: ["OpenClaw", "可及性", "accessibility"]

输入: "MCP 和 function calling 有什么区别？"
提取: ["MCP", "function-calling", "tool-use"]
```

**完成条件**: 得到 2-4 个搜索关键词列表

---

## Phase 2: 文件扫描

**执行者**: 文件系统操作

**目标**: 找到所有与关键词相关的笔记

### 2.1 Atom 文件名匹配

```
对每个关键词:
  glob 40-Atoms/ 下文件名包含关键词的 .md 文件
  （大小写不敏感，支持部分匹配）
```

### 2.2 Atom 正文搜索

```
对每个关键词:
  grep 40-Atoms/ 中正文或 frontmatter 包含关键词的文件
  返回文件路径 + 匹配行上下文（-C 2）
```

### 2.3 Source Note 摘要搜索

```
对每个关键词:
  grep 00-Inbox/ 中 ## Summary 部分包含关键词的文件
  返回文件路径 + Summary 全文
```

**优先级规则**:
- Atom 笔记优先（已提炼的概念，信息密度高）
- Source Note 作为补充（原始摘要，可追溯来源）

**完成条件**: 得到匹配文件列表，按 Atom / Source 分组

---

## Phase 3: 相关性排序

**执行者**: AI 分析扫描结果

**目标**: 对扫描到的文件按相关性排序

**排序规则**:

| 优先级 | 条件 | 说明 |
|--------|------|------|
| 1 | 文件名与关键词完全匹配 | 最精准 |
| 2 | Atom 正文多次命中关键词 | 信息密集 |
| 3 | Atom 正文单次命中 | 相关 |
| 4 | Source Note Summary 命中 | 原始来源 |

**过滤**:
- 去掉只有标签命中但正文无实质内容的笔记
- 相关性极低（仅单词出现，无上下文）的结果可丢弃

**完成条件**: 得到排好序的相关笔记列表（通常 3-8 个）

---

## Phase 4: 综合回答

**执行者**: AI 基于扫描结果生成回答

**目标**: 用自然语言回答用户的问题，内嵌 [[wikilink]] 引用

**规则**:
1. 回答语言跟随用户提问语言（中文问题用中文回答）
2. 每个关键断言都附 [[wikilink]] 引用具体笔记
3. 综合多个笔记的观点，而非逐条复述
4. 若发现矛盾观点，明确指出
5. 若信息不足，说明知识库当前覆盖范围和缺口

**输出格式**:
```markdown
[自然语言回答，融合多个相关笔记的信息]

根据 [[atom-1]] 的记录，[观点 A]。

[[atom-2]] 进一步指出，[观点 B]。结合 [[source-note-1]] 中的原始数据，[综合结论]。

[如有矛盾] ⚡ 注意：[[atom-3]] 与 [[atom-4]] 在这一点上有分歧：...
```

**完成条件**: 生成带引用的自然语言回答

---

## Phase 5: 来源追溯

**执行者**: AI 整理引用列表

**目标**: 在回答末尾列出所有引用的笔记路径，便于用户深入查看

**输出格式**:
```markdown
---

**引用笔记**:
- `40-Atoms/atom-1.md`
- `40-Atoms/atom-2.md`
- `00-Inbox/source-note-1.md`
```

**完成条件**: 所有在回答中引用的笔记都列出完整路径

---

## 完成条件（端到端）

- [ ] 从问题中提取了 2-4 个关键词
- [ ] 扫描了 40-Atoms/ 和 00-Inbox/
- [ ] 回答用自然语言组织，非逐条列表
- [ ] 回答中包含 [[wikilink]] 引用
- [ ] 末尾列出所有引用笔记的完整路径
- [ ] 若知识库无相关内容，明确告知而非捏造
