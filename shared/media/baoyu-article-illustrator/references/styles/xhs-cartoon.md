# xhs-cartoon

Cute cartoon infographic style optimized for Xiaohongshu (Little Red Book) with Morandi colors and hand-drawn aesthetics

## Design Aesthetic

Eye-catching cartoon infographic style tailored for social media. Morandi-inspired soft color palette creates a warm, approachable feel. All visual elements are hand-drawn or cartoon-style — no realistic images or fonts. Generous white space with focused information density. Feels like a well-designed hand-made sticker or cute notebook page.

## Background

- Color: Morandi palette — Cream (#FFF8F0), Milky White (#FEFCF3), Light Pink (#FFE4E1), Mint Green (#E8F5E8)
- Texture: None or subtle paper grain

## Visual Elements

- Hand-drawn style text (NOT realistic fonts)
- Highlighter marker effect on keywords
- Cartoon emoji-style icons
- Hand-drawn sticker elements
- Sticky note / memo pad textures
- Speech bubbles and dialogue boxes
- Simple cartoon character illustrations (for people)
- Doodle borders and dividers
- Star, heart, sparkle decorations

## Typography

- All text must be hand-drawn / handwritten style
- Large bold titles with cartoon feel
- Keywords emphasized with fluorescent highlighter effect
- Bullet points use cute icons instead of dots
- No serif or sans-serif realistic fonts

## Aspect Ratio

- Portrait preferred: 3:4 or 9:16 (optimized for mobile/social)
- Can also work in 16:9 for article illustrations

## Style Rules

### Do

- Use Morandi soft color palette consistently
- Keep all elements hand-drawn / cartoon style
- Add cute decorative elements sparingly
- Use highlighter effects for key information
- Maintain generous white space
- Focus on 1 core point per illustration
- Use cartoon substitutes for real people (never refuse to generate)
- Keep information density moderate — easy to scan

### Don't

- Use realistic images, photos, or photorealistic rendering
- Use realistic / standard fonts (serif, sans-serif)
- Overcrowd with too many elements
- Use dark, moody, or corporate color schemes
- Add complex backgrounds or busy textures
- Include too much text — keep concise

## Best For

Social media infographics, Xiaohongshu posts, knowledge cards, tutorial summaries, tip lists, fun facts, educational content for casual audiences, article companion images for social sharing
